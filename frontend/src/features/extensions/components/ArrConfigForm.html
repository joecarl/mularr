Tells Mularr how to work with : which search providers its automatic searches use and, optionally, the wanted list sync, where Mularr periodically reads the monitored items without a file, searches the providers for them and publishes the matching releases in its Torznab RSS feed, where picks them up on its next RSS sync.

Needs the instance URL and API key. Leave it off to only choose the search providers below.
Used by the periodic search of the wanted titles and by the automatic searches itself runs through the Torznab indexer (). Leave out a network whose results are too unreliable for unattended downloads; only providers with an enabled extension are listed. With none selected the wanted list is never searched and the indexer answers those searches with no results.
